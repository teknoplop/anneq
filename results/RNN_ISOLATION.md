**#11 only rescales the learning rate.** "#10 only" at η gives exactly the same output as "#10 + #11" at
4η (= nodes_1 × η). The #11 fix divides the δ·u term of the RTRL sensitivity recursion by nodes_1; the
recursion is linear in the sensitivities, so every sensitivity, and so every weight update, shrinks by
the same factor. In effect the 1995 code ran RTRL with a learning rate 4× the one written down.

**#10 is the bug that changed the conclusion.** With the feedback unwired no learning rate lets the RNN
match the ADALINE (best: 3.7e-3 / 5.5e-4 at η = 0.008). With #10 fixed, η from about 0.008 to 0.02
beats it. At the 1995 η = 0.003 the #10-fixed RNN still loses (4.1e-3 / 7.8e-4), because the rate had
been tuned with the bug present: the fix had to be followed by re-tuning η upwards about 3–7×.
